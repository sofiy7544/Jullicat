# Jellycat Ukraine 🧸

Магазин-витрина Jellycat (один файл `index.html`). Теперь это **PWA** — можно открыть
на iPhone в Safari, добавить на экран «Домой» и пользоваться как приложением, даже офлайн.

## Как открыть на iPhone локально (та же Wi-Fi сеть)

Service worker и установка «как приложение» работают только по `http(s)`, поэтому
открывать нужно через локальный сервер, а **не** двойным кликом по файлу (`file://`).

1. На компьютере, где лежит проект, запусти сервер:

   ```bash
   python3 serve.py
   ```

   (нужен только Python 3 — он уже есть на macOS и в большинстве Linux)

2. В терминале появятся две ссылки, например:

   ```
   На этом компьютере:        http://localhost:8000
   На iPhone (та же Wi-Fi):   http://192.168.0.105:8000
   ```

3. На iPhone убедись, что он в **той же Wi-Fi сети**, что и компьютер, и открой
   ссылку для iPhone в **Safari**.

4. Чтобы пользоваться как приложением: **«Поделиться» → «На экран Домой»**.
   После этого магазин открывается на весь экран и работает офлайн.

> Свой порт: `python3 serve.py 5050`
> Остановить сервер: `Ctrl+C`

## Открыть с любого устройства (GitHub Pages)

В репозитории настроен автоматический деплой на GitHub Pages
(`.github/workflows/pages.yml`). Публикация запускается:

- автоматически при пуше в ветку `main`;
- или вручную: вкладка **Actions → Deploy to GitHub Pages → Run workflow**.

Workflow сам включает Pages (`enablement: true`), отдельно щёлкать тумблер в
настройках не нужно. После первого успешного запуска сайт будет доступен по
адресу вида `https://<пользователь>.github.io/<репозиторий>/` — его можно открыть
на iPhone из любой сети и так же добавить на экран «Домой».

> Чтобы запуск по пушу заработал, этот workflow должен попасть в ветку `main`
> (слить эту ветку в `main`). Запуск вручную через **Run workflow** возможен
> только после того, как файл окажется в `main`.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | сам магазин (вся вёрстка, стили и логика корзины) |
| `manifest.webmanifest` | манифест PWA (имя, иконки, цвета) |
| `sw.js` | service worker — офлайн-кэш |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | иконки приложения |
| `make_icons.py` | генератор иконок (если захочешь поменять дизайн) |
| `serve.py` | локальный сервер для просмотра на телефоне |
| `.github/workflows/pages.yml` | автодеплой на GitHub Pages |
